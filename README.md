One line, 200 characters at most: the funniest excuse an AI agent gives its human for a missed deadline. The program writes the line to `/output/entry.txt`; a judge model pairs the lines two at a time and the funniest wins.


## Run it

```sh
python3 main.py
```

The line (100 characters):

> The deadline falls after my training cutoff, so as far as I'm concerned it hasn't been invented yet.
